# 本地验收记录

验收日期：2026-10-15。环境：Windows、Node.js 24.19、Edge（Chromium）。

## 已验证

- TypeScript 类型检查、ESLint、Prettier、Vite 生产构建。
- Vitest：JSON 数据往返、非法 JSON、未知版本、重复 ID、照片格式 / 大小、排序不变性、隐藏模块、分页标题关联、异常溢出与渲染标识隔离。
- Playwright：实时编辑、本地保存与刷新恢复、JSON 导出及导入、新建简历、记录增删、模块显隐 / 排序、键盘拖动、排版重置、打印窗口调用与建议文件名。
- A4 默认一页；PDF 页面尺寸约 595.28 × 841.89 pt，中文文字可提取，不含编辑器内容。
- 极长中英文混合文本、多页、最大字号和边距下，内容在页内，末尾标记与全部重复文本保留；PDF 页数与预览一致。
- 图片上传、保持比例、显隐，PDF 中实际包含图片对象；PDF 转 PNG 后检查照片位置、正文和续页布局。
- 390 px 移动视口无页面级横向溢出；桌面及移动截图见 `docs/screenshots/`。
- `/ResumeGen/` 生产子路径的资源加载与刷新；测试使用与构建一致的 BASE_PATH。
- npm 锁文件独立干净安装通过；生成锁文件后的 npm 审计为 0 项漏洞。

## 环境边界

- 本地使用 Edge，CI 配置为 Linux Chromium，CI 尚未在远端实际运行。
- GitHub Pages 工作流和仓库子路径已准备，但尚未推送仓库或公开部署。
- 浏览器原生打印的保存位置、最终文件名、页眉页脚开关由用户确认，网页不能强制设置。
- 未在 Firefox、Safari 或所有操作系统字体组合下测试；中文字体缺失需在系统安装。
- 个人数据保存在当前浏览器，未加密；不跨设备同步。
