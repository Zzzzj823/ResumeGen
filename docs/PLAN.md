# ResumeGen 开发计划与验收标准

## 阶段一：规划

初始目录仅有 `references/resume-reference.png`，没有既有代码。参考图约为 A4 比例：姓名顶部居中，联系方式两行居中，照片在右上角；正文从教育开始，接实习、项目、专业技能、其他。标题加粗，教育附近有浅灰背景，其余模块使用细灰横线；经历名称左对齐、日期右对齐，正文紧凑。图片内容经过模糊处理，不推测真实个人资料。模板使用可编辑 HTML 文本，不使用背景截图。

技术方案：React + TypeScript + Vite；Zustand 保存状态；Zod 验证版本化 JSON；dnd-kit 实现鼠标、触摸和键盘排序；本地照片仅允许 JPEG/PNG/WebP，经过解码缩放；localStorage 保存草稿并报告失败。所有运行时资源本地打包，无远端个人数据传输。

数据结构：Resume { version, basics, sections, settings }。Section { id, kind, title, visible, entries }。Entry 包含稳定 id、名称、次标题、地点/技术栈、日期、描述；kind 决定编辑字段含义。基本信息固定为页首，经历模块和记录均可排序。

组件：Toolbar 负责文件和打印命令；Editor 管理表单、排序和照片；Classic 模板负责独立渲染；Preview 测量文本并分页；store 管理数据更新和保存；utils 管理输入校验、照片、文件和分页算法。

## 阶段二：基础项目

搭建构建、lint、格式化、单元测试；实现左右编辑与预览布局、示例数据、状态更新。验收：生产构建通过，表单修改立即映射到预览。

## 阶段三：模板

实现 Classic Professional 的毫米 A4 尺寸、姓名、照片、分隔线与日期对齐。统一字号、行距、边距变量。验收：默认示例一页，中文和英文清晰，不存在内容重叠。

## 阶段四：完整编辑

实现模块及记录增删、拖拽、键盘排序、隐藏，排版设置、照片和 JSON。验收：完整数据往返一致，非法 JSON/远程照片被拒绝，刷新恢复草稿，存储失败可见，重置模板保留内容。

## 阶段五：分页与 PDF

使用真实 DOM 测量，按行拆分长段落，将相同分页结果用于屏幕与打印；模块标题与首条内容保持同页，续页标注模块名。设置 @page A4、零外部页边距、独立打印样式。验收：Playwright 检查 A4 尺寸、长文本、多页、照片、移动视口，生成 PDF 并提取中文文本，验证页数及纸张尺寸。

浏览器限制：原生打印弹窗不能强制自动下载或最终文件名；通过 document.title 建议 `姓名_简历.pdf`。用户选择另存为 PDF、A4、100% 比例、关闭页眉页脚。不同操作系统的本地中文字体可能略有差异，页面测量会等待字体就绪。

发布：提供 GitHub Actions 验证并部署 Pages，构建时通过 BASE_PATH 配置仓库子路径；本次仅本地开发，实际推送与开启 Pages 由仓库维护者完成。
